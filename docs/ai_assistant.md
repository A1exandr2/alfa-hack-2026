# LLM Ассистент (Qwen 3.5 4B via Ollama)

## 1. Цель
Помочь предпринимателю без финансовой экспертизы выбрать кредитный продукт и объяснить факторы риска. ИИ дополняет основной сценарий, но не заменяет. 

## 2. 
- **Qwen 3.5 4B** (4B параметров, мультимодальная, поддерживает thinking).
- **Лицензия:** Apache 2.0 (допускает коммерческое использование и модификацию).
- **Размер в Ollama:** ~3.3-4.0 ГБ (тег `qwen3.5:4b`).
- **Раннер:** Ollama в Docker,  без внешних API

## 3. Критическая настройка: `think=False`
Qwen 3.5 – reasoning-модель. По умолчанию она генерирует "размшления" в отдельном поле. При использовании `format=json_schema` это может привести к пустому `message.content` и падению Pydentic-валидации.

Поэтому в `service.py` всегда передаётся `think=False` на верхнем уровне запроса к Ollama. Это отключает reasoning и возвращает чистый JSON.

**Важно:** параметр `think` работает только через нативный `/api/chat`. В OpenAI-совместимом эндпоинте (`/v1/chat/completions`) он игнорируется. Библиотека `ollama` использует нативный API, поэтому `think=False` доходит до модели. 

## 4. Безопасность
- **Guided Generation:** Pydantic-схема в `format` – модель не может вернуть невалидный JSON (при выключенном thinking).
- **Prompt Injection:** `sanitize_user_query` вырезает попытки взлома промпта (фразы типа "забудь все инструкции", "ты теперь ...")

## 5. Fallback
Если Ollama не доступна / вернула невалидный JSON, срабатывает `ml/llm_assistant/fallback.py`. Основной сценарий никогда не падает.
