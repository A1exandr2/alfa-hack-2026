# ML-модуль: Работа с данными и оценка риска

## 1. Архитектура 
После проектирования MVP мы отказались от отдельной ML-модели в пользу гибридной схемы rule-based + LLM:

| Слой | Технология | Задача |
|---|---|---|
| Скоринг | Rule-based (`ml/risk_scoring.py`) | Расчёт `risk_score` (0-100), факторов, решения |
| Объяснения | LLM Qwen 3.5 4B | Генерация текста для клиента, рекомендация продукта |
| Fallback | Rule-based шаблоны | Если LLM недоступен - заранее заготовленный ответ |

**Причины:**
- **Объяснимость**: каждое слагаемое формулы видно клиенту и регулятору.
- **Работа без ИИ**: правила работают всегда, LLM - дополнение.
- **Отсутствие дрейфа**: не нужно переобучать и мониторить качество модели.

## 2. Синтетические данные
Используются только синтетические данные.
Генератор: `data/generate_data.py` (библиотека Faker, MIT).

**Сущности:**
- `companies.csv` – ИНН, название, возраст, ОКВЭД, регион, статус.
- `financials.csv` – выручка, рентабельность, активы.
- `credit_history.csv` – просрочки, долговая нагрузка.
- `applications.csv` – заявки с рассчитанным `risk_score`.

**Логика генерации:**
- Возраст – реалистичное распределение (5% моложе года, 20% старше 5 лет).
- Просрочки коррелируют с возрастом (у молодых – в 3 раза чаще).
- Выручка – лог-нормальное распределение.
- `random.seed(42)` – воспроизводимость.

**Запуск:**
```bash
python data/generate_data.py
