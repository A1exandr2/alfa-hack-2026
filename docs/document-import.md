# Импорт финансовых документов

Раздел «Документы» и ссылка «Загрузить отчётность» во вкладке финансов открывают загрузку. Требуется привязанная компания.

Поддерживаются PDF (до 20 страниц), PNG/JPEG/WEBP/BMP/TIFF, XLSX, DOCX, CSV/TSV, XML, TXT и JSON. Размер — до 10 МиБ. Для старых DOC/XLS, HEIC, архивов и защищённых паролем файлов требуется преобразование. Нельзя гарантировать извлечение всех показателей из любого документа.

## Процесс

1. `POST /api/v1/company/documents/preview?filename=report.pdf` получает бинарное тело (`application/octet-stream`) с обычной Bearer-авторизацией.
2. Чтение проходит в отдельном процессе с ограничениями времени/памяти; XML запрещает сущности, ZIP проверяется на объём распаковки. Макросы и формулы не выполняются. XLSX читает сохранённые значения формул.
3. Poppler читает текст PDF. Страницы без текста и изображения распознаёт Tesseract (`rus+eng`). Для длинных документов отбираются строки с показателями с явным предупреждением.
4. Локальная Qwen возвращает структурированные значения, цитаты, год и единицы. Недоступность/некорректный ответ модели не порождает демоцифр: пользователь получает текст и пустые поля для ручного заполнения.
5. Числа проверяются по найденным цитатам. Суммы масштабируются только при подтверждённых единицах документа. Неизвестные поля не подменяются нулями. Другой распознанный ИНН блокирует сохранение.
6. Предпросмотр редактируется пользователем. `POST /api/v1/company/documents/{id}/confirm` требует `accepted:true` и хотя бы одну непустую группу `financials`/`credit_history`. Записываются только явно переданные поля. Двойное подтверждение отклоняется.

Пример подтверждения:

```json
{"accepted":true,"financials":{"report_year":2025,"revenue_annual":"1250000.00"},"credit_history":{"overdue_count":0}}
```

Источник сохранённых полей — `DOCUMENT_USER_CONFIRMED`. Это проверка пользователем, не верификация банком, ФНС или БКИ. Такие поля учитываются как ручные и не позволяют автоматическое положительное решение. Отчёт не становится «полученным из БКИ» только потому, что загружен пользователем.

## Хранение

Исходный файл временно хранится в `/tmp` и удаляется после чтения. В таблице `document_imports` сохраняются имя, SHA-256, распознанные предложения, цитаты, фрагмент текста, пользователь, компания, время и подтверждённые значения. В `field_sources` показателей хранится ссылка на импорт и признак правки пользователем. Прежние снимки заявок не меняются.

`DELETE /api/v1/company/documents/{id}` удаляет неподтверждённый предпросмотр своего аккаунта и компании. Подтверждённые импорты сохраняются для происхождения данных. Смена компании не даёт применить старый предпросмотр к другой компании.

## Среда

Docker-образ включает Poppler, Tesseract и русский/английский языки OCR; Python — Pillow, openpyxl, defusedxml. Используется существующая локальная Ollama через `OLLAMA_HOST`/`OLLAMA_MODEL`. Приём документов не отправляет их внешним API. Nginx допускает 11 МиБ тела и ожидание обработки до 240 секунд. Одновременно обрабатывается один документ; остальные запросы получают 429 для повторной попытки.

### Длинные отчёты и сравнительные колонки

При отборе контекста приоритет получают строки показателей и заголовки годовых колонок. Единицы берутся из явного объявления в документе или кода ОКЕИ; фраза о том, что поля кабинета ожидают рубли, не меняет единицы источника. Однозначные строки дополнительно проверяются независимо от Qwen: выбирается колонка указанного отчётного года, противоречивые значения не объединяются и не суммируются. Цитаты проверяются по полному прочитанному тексту. Исходный 18-страничный тестовый PDF входит в регрессионные проверки всех девяти показателей.
