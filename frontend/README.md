# Кабинет предпринимателя

Адаптивный frontend по `/home/sasha/макет.svg`. HTML/CSS/JavaScript без этапа сборки и сторонних runtime-зависимостей.

Запуск общего приложения: `make up-gpu` (NVIDIA) или `make up` (CPU). Кабинет: http://localhost:8080, документация API: http://localhost:8080/docs.

Nginx отдаёт frontend и проксирует `/api/v1`, `/docs`, `/redoc`, `/openapi.json` в backend. В Docker Compose исходники frontend подключены read-only; изменения HTML/CSS/JS доступны после обновления страницы. После изменения конфигурации Nginx пересоздайте сервис: `docker compose --env-file .env up -d --force-recreate nginx`.

Реализованы регистрация, вход, привязка компании, главная с описанием платформы и показателями API, финансы во вкладке компании с отдельным включением редактирования, каталог, создание/редактирование черновика, отправка заявки, NEED_MORE_DATA, история, решение и ручная проверка для REVIEWER. Дублирующее меню шагов убрано. После входа открывается главная. Компанию можно отвязать, сохранив историю заявок. Реквизиты из реестра доступны после серверной настройки DADATA_API_KEY. JWT хранится в sessionStorage, выход очищает его. Запросы авторизуются backend; роли не назначаются через frontend.

Предложения, принятие условий, скачивание договоров и новости не имитируются: соответствующего API пока нет. На графике показаны реальные годовые показатели API, поскольку API не предоставляет помесячную историю. Данные поставщиков и кредитные решения демонстрационные.

Проверки: `node --check frontend/app.js`, `cd frontend && npm ci && npm test`. Интеграционные проверки интерфейса через DOM требуют jsdom (dev-зависимость; устанавливается в изолированном тестовом каталоге).


### Заявки, документы и аккаунт

На странице заявок доступны совместный поиск по номеру, продукту и цели, фильтр статуса и сортировка по дате либо сумме. Раздел «Документы» скачивает JSON-выгрузки компании, финансов и заявок с решениями и историей; это не банковские договоры.

Колокольчик получает реальные изменения статусов из API истории заявок при открытии кабинета, возвращении во вкладку и каждые 30 секунд, пока вкладка видима. Отметки о прочтении хранятся в localStorage отдельно для каждого аккаунта и браузера. Это уведомления внутри кабинета; закрытый браузер их не получает. Аватарка открывает модальное окно аккаунта; выход из сессии находится в этом окне.


### Загрузка отчётности

Раздел «Документы» принимает PDF, изображения, XLSX, DOCX, CSV/TSV, XML, TXT и JSON (до 10 МиБ, PDF до 20 страниц). Разбор через OCR и локальную Qwen открывает редактируемый предпросмотр с цитатами и текущими значениями. Сохранение требует явного подтверждения; пустые поля остаются без изменений. Это неподтверждённый источник для кредитования. Подробнее: [импорт документов](../docs/document-import.md).

### Телефоны

До 700 px включается нижняя навигация с пятью разделами; профиль и уведомления остаются в закреплённой шапке. Заявки отображаются карточками с подписями полей. Формы и загрузка документа переходят в одну колонку, поля используют числовую клавиатуру по назначению. Учтены безопасные отступы экрана и изменение видимой высоты при открытии клавиатуры в модальном окне. Минимальная ширина — 320 px.

DOM-проверки покрывают переходы, подписи карточек, клавиатуры и обработку VisualViewport. Визуальная проверка на физических iOS/Android устройствах ещё требуется.
