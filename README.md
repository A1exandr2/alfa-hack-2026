# credit

Умный кредитный кабинет предпринимателя — проект для Альфа Хак.

- `frontend/` — интерфейс, зона Frontend.
- `backend/` — API и бизнес-логика, зона Backend.
- `ml/` — обучение, эксперименты и скоринг, зона ML.
- `devops/` — Docker, CI/CD и развертывание, зона DevOps.
- `docs/` — общая документация: каждый описывает запуск и использование своей части.
- `data/` — общие синтетические данные.

Внутри своей папки каждый сам выбирает структуру. Чужие части меняем по согласованию.

## Как работаем

Модульный монолит: один бэкенд, разделенный на логические модули. Frontend работает через его API; готовый скоринг подключается внутрь бэкенда. ML-обучение остается в `ml/`. Контракты API и скоринга согласуем между участниками.

Каждый делает задачи в своей ветке от `main`, затем открывает PR в `main`. Документацию обновляем вместе с кодом. Общий запуск будет в корневом `docker-compose.yml`, его собирает DevOps вместе с командой.

Пока в репозитории только начальная структура, приложение еще не реализовано.

Локальная проверка секретов: `make gitleaks`. Инструкции и статус проверок: [docs/devops.md](docs/devops.md).
